# Ocloo Connector for Shopify — free trial, Odoo 17.0

This branch holds the `mirak_shopify_connector_trial` module for **Odoo 17.0**.

Two-way synchronization between Odoo and Shopify: catalog, stock, orders, customers, invoices,
payments, payouts, returns and real-time webhooks.

**Trial limits:** 25 linked products, one Shopify store, 30 days counted from installation.
Every feature of the connector is available during the trial.

## Install

1. Copy the `mirak_shopify_connector_trial` folder into your addons path and restart Odoo.
2. Update the apps list and install *Ocloo Connector for Shopify (Free Trial)*.
3. Create a store record: shop domain, Admin API token or OAuth install link, warehouse.
4. Run the first synchronization and follow the dashboard.

The full edition removes the limits and needs no license key. See the
[main branch](../../tree/main) for the complete description.
