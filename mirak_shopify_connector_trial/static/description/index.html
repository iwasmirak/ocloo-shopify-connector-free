Requirements

  • Odoo 19.0 — Community or Enterprise, with Sales, Inventory and Invoicing.
  • A Shopify store with Admin API access (custom app token or OAuth).
  • Python cryptography.
  • An HTTPS domain for the webhooks to reach Odoo.

Good to know

  • The trial links 25 products, one Shopify store, for 30 days counted from installation. Every feature of the connector is available during the trial.
  • One Shopify location per Odoo warehouse; multi-location needs Shopify plans that allow it.
  • Webhooks need a reachable HTTPS instance; the scheduled synchronization works without them.
  • The module is not affiliated with Shopify Inc.
